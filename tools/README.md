# Картинки для README

Снимки цветного вывода в `docs/*.svg` — не рисунки от руки, а настоящий вывод
библиотеки. При смене палитры их нужно пересобрать, иначе README покажет
устаревшие цвета:

```
tools/make-screenshots.sh
```

Скрипт собирает демонстрационную программу с библиотекой, пропускает её вывод
через `ansi-to-svg.py` и кладёт результат в `docs/`.

SVG выбран вместо PNG намеренно: он чёткий на любом экране, весит около
килобайта и правится как обычный текст.

# Плата понарошку

Чтобы посмотреть веб-страницу журнала, плата не нужна:

```
python3 tools/fake-board.py
```

Скрипт поднимает тот же поток, что отдаёт `FmtWeb.h`, — с тем же форматом
строки и тем же заголовком для чтения с диска. Сначала идёт история за
несколько дней, потом строки по одной.

```
--port 8080      порт
--days 3         за сколько дней история
--lines 200      строк в истории
--interval 1.0   секунд между новыми строками
```

История за несколько дней нужна, чтобы проверить поиск и переход к дате: на
десятке свежих строк они ничего не показывают.
