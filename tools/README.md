# Картинки для README

Снимки цветного вывода в `docs/*.svg` — не рисунки от руки, а настоящий вывод
библиотеки. При смене палитры их нужно пересобрать, иначе README покажет
устаревшие цвета:

```
tools/make-screenshots.sh
```

Скрипт собирает демонстрационную программу с библиотекой, пропускает её вывод
через `ansi-to-svg.py` и кладёт результат в `docs/`.

SVG выбран вместо PNG намеренно: он чёткий на любом экране, весит около
килобайта и правится как обычный текст.
